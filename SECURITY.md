# Security Policy

## Supported Versions

We provide security updates for the following versions of TerangaHost:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The TerangaHost team takes the security of our software and user infrastructure seriously.

If you believe you have found a security vulnerability in TerangaHost (such as unauthorized privilege escalation, SSH credential leakage, or remote code execution risks):

1. **Please do NOT disclose it publicly** on GitHub Issues or social media.
2. Contact the maintainers privately via GitHub Security Advisories or by email at `security@terangahost.org` (or directly via the primary maintainer's profile).
3. Provide a clear description of the vulnerability, steps to reproduce, and proof of concept if applicable.

We will acknowledge receipt of your vulnerability report within 48 hours and work with you to patch and disclose the issue responsibly.
